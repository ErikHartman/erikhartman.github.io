To display a different complex:
1. Add the PDB (or mmCIF) coordinate file to this directory.
2. Update content/structure.json: src, format, chain IDs,
   proteinLabel, peptideLabel, sourceUrl, sourceLabel, and example.
3. Remove initialQuaternion or replace it with the preferred viewing angle.
4. Run the website build and inspect Ribbon and Surface at desktop/mobile sizes.

The current quaternion points the p53 peptide toward the camera. It is a
viewing transform only; atomic coordinates are unchanged. Only configured
protein/peptide chains are drawn. The viewer does not run predictions.
